# Healthcare Analytics Dashboard

## Overview

An interactive Healthcare Analytics Dashboard built using Microsoft Excel to analyze patient admissions, billing performance, insurance providers, medical conditions, and test results.

|-----|-------|

| Emergency Admissions | 13,222 |
| Normal Test Results | 33.3% |

## Dashboard Features

- Interactive Slicers for dynamic filtering
- KPI Cards for quick performance tracking
- Monthly Admission Trend Analysis
- Medical Condition Distribution Analysis
- Billing Amount Analysis by Medical Condition
- Insurance Provider Analysis
- Test Result Distribution Analysis
